# 日常生活圖示包

30 個原創、獨立 PNG 圖示，皆為透明背景並採用一致的扁平微等角風格：深藍描邊、柔和藍／綠／黃／珊瑚色與淡陰影。適合錢包 App、記帳、支付與生活服務入口。

```text
money/       12 個：銀行、行動支付、信用卡、提款、轉帳、繳費、收據、分析、儲蓄、投資、保險、稅務
mobility/     5 個：大眾運輸、加油、停車、計程車、旅行
daily/       13 個：餐飲、咖啡、雜貨、便利商店、藥局、醫療、健身、教育、娛樂、水電、住家、禮物、寵物
```

全部為原創的通用功能圖示，未含任何品牌商標。建議在 48–128 px 顯示；小於 32 px 時可改用線性 SVG 圖示，以維持辨識度。
## 新增的線條圖示

`outline.svg` 是可重用的 SVG sprite，包含飲食、交通、娛樂、購物、醫療、居家、運動、旅遊、教育、其他十個大類，以及支出、收入、轉帳三個交易模式圖示。符號 ID 分別為 `dl-dining` 等 `dl-*` 名稱與 `dl-mode-expense`、`dl-mode-income`、`dl-mode-transfer`。全部使用 24×24 viewBox、1.8 px 圓角描邊與透明背景，適合縮小顯示。
